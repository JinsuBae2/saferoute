# A01 불꽃 검출 단절 복구 후보 비교

2026-11-10, #135. #125의 개발 FIRE 정밀도50%(TP1/FP1/FN0)를 개선하기 위해
실제 재추론을 수행했다. **이번 후보 중 채택할 개선안은 없었다.** 기존 설정·정답·사건 매칭을
유지하며 불꽃 문제가 해결됐다고 표시하지 않는다. [원본 해시와 재계산 결과](../../deploy/resource-checks/2026-11-10-ai-fire-recovery-candidates.json)에
실패와 사전 거부를 포함했다. 평가용 영상·구간 정답은 사용하지 않았다.

## 문제와 비교 방법

개발 촛불 영상의11512ms 이후 일부 프레임에서 현재 불꽃 검출이 끊기고 다시 나타난다.
기존 매칭 규칙은 같은 클래스 ALARM 사이 간격이1000ms를 넘으면 별도 예측 사건으로 센다.
따라서 정상 배경에 대한 오탐이 없어도 동일 정답 사건에 대한 두 번째 예측이FP가 된다.
이 중복을 없애려고 정답·1000ms 매칭·현재 프레임 검출 조건을 바꾸거나 이전 박스를 새 관측으로
전송하지 않았다. 모델이 현재 영상에서 검출을 회복하는지 확인했다.

기준은 #125의 xiazh FP32 ONNX/OpenVINO/CLAHE/native 프로필이다. 개발7개 원본과 기존
development 정답으로 비교하며 confidence0.25/window1500/min2를 유지한다.
250ms 후보만 분석 간격을 변경했고, 두 공개 모델 진단은640/500ms·명암 보정 없음·CPU4로 실행했다.
영상 전체를 순서대로 읽고 예정된 시각에서 실제 추론했다. 재생 대기·API 전송 없는 오프라인
시험이므로 샘플 수를 서버 처리량·늦은 샘플 폐기0·관측 만료0의 증거로 해석하지 않는다.

정상 표본은4개137.320초다. 같은 표본을 다시 사용했으므로 독립 정상 자료가 늘어난 것이 아니다.
250ms에서 첫 대응 FIRE 지연501→267ms지만 정밀도는50% 그대로이고 SMOKE 정밀도가
100%(2/2)→66.67%(2/3)로 나빠졌다. SMOKE 대응 지연 최댓값은2000ms다.
mfranzon은 FIRE 재현율0/1, SMOKE 재현율1/2다. 미검출의 지연을0이나 통과로 표시하지 않는다.
불꽃 전용 진단 JSON의 SMOKE FN2는 연기 출력 자체가 없는 결과이며 두 클래스 모델의
성능 비교나 실제 연기 지원으로 간주하지 않는다.

### 현재 프레임의 불꽃 주변 확대 진단

기존11512ms 검출 박스의 중심에서 긴 변의2배/4배 정사각형을 잡고 영상 경계로 제한해,
11512~14014ms의6개 현재 프레임을 각각 다시 추론했다. 이전 박스를 출력한 것이 아니다.
두 배율 모두 핵심12012/12513ms에서 검출이 없었다.4배는13013ms 검출을 회복했지만
단절 해결 근거가 없어 채택하지 않았다.12회 부분 진단이며 전체7개 성능·실시간 처리를
입증하지 않는다. 박스는 crop 좌표에서 원본 좌표로 환산해 원본 JSON에 보존했다.

## 재현과 남은 작업

실행 소스 기준은 develop `76cbe699`다. 공통 AI lock, #125의 ONNX/OpenVINO lock과 검증된
기존 개발7개 manifest를 사용했다. 영상·가중치·전체 추론 원본은Git 밖에 보존한다.

- 250ms: `configs/ai.xiazh.clahe.native.development.json`을 별도 로컬 설정에 복사하고
  `interval_ms`만250으로 변경한다. 그 외 모델/옵션은 동일하다.
- mfranzon: 기존 `configs/ai.xiazh.development.json`을 별도 복사하고 `model_path`와
  `model_sha256`만 위의 실제 파일에 맞춘다. 기존 제품 Detector로 두 클래스 검사를 수행한다.
- Priyanshu 불꽃 전용 모델은 제품 worker에 연결하지 않는다. 별도 진단의 입력/클래스/프레임별
  출력·스크립트 해시를 공개 JSON과 로컬 `runs/a01-135-fire-only-screen*`에 보존했다.
- 오프라인 실행은 `runs/a01-135-interval250-screen.py`, `a01-135-mfranzon-screen.py`,
  `a01-135-fire-only-screen.py`; 확대 진단은 `a01-135-crop-probe.py`다. 같은 runs 폴더의
  원본을 `a01-135-proof.py`가 읽기 전용으로 재집계해 공개 JSON과 대조한다.

후보가 정확도 비교에서 탈락해 이번에는 서버 전달·30분 시험을 반복하지 않았다.
