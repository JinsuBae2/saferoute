# 담당 1 구현·검증 인계와 자동 보류

2026-11-10 KST 기준. 조대성(Rinhaze)의 담당은 불꽃·연기 AI, 실제 영상 처리·평가와 A05 설명 작업자다. 사용자는 잔여 작업의 구현·검증·검토·규칙에 따른 머지를 승인하고, 불명확한 항목은 추가 질문 없이 건너뛰도록 지시했다. 아래 보류는 그 지시에 따른 것으로, 다른 팀의 합의·독립 검수 완료를 뜻하지 않는다.

개발 7개 기준은 정상 4개 137.320초 오탐 0, FIRE 사건 정밀도 20%·재현율 100%, SMOKE 정밀도 100%·재현율 50%다. **Tai Po 연기 1건 미검출과 촛불 중복 예측 4건이 남아 있다.** 전송 성공과 모델 성능 합격을 혼동하지 않는다. 개발 후보 설정은 640/500ms/confidence 0.25/window 1500ms/min_detections 2이며 최종 채택 선언은 아니다.

후속 [A04-4 confidence 비교](a04-confidence-comparison.md), #102에서 confidence만 0.10으로 낮춘 후보를 개발 7개 전체에 실행했다. 미검출/촛불 중복은 그대로이고 정상 FIRE 오탐 6건·SMOKE 오탐 5건이 생겨 **이 후보는 채택하지 않았다.** 첫 ffprobe 미설정 실패와 이후 전체 실행을 모두 보존했으며 기본 설정은 0.25를 유지한다. 이 비교 완료를 미검출 해결 또는 최종 모델 채택으로 표시하지 않는다.

추가로 [A01-4 대체 모델 비교](a01-alternative-models.md), #105에서 기존 모델과 대체 후보 2개를 개발 7개 전체에 실행했다. luminous는 정상 오탐·미검출 때문에 미채택이다. xiazh는 Tai Po 연기를 검출하고 촛불 중복을 줄인 후속 개발 후보지만 FIRE·SMOKE 중복 사건이 각 1건 남는다. 별도 설정과 실제 클래스 순서 호환을 제공하며 기본 모델은 유지한다. [A01-5](a01-alternative-server.md), #111에서 새 후보와 기준 모델의 서버7개/358샘플·전송·CPU 비교를 완료했고 누락/관측 만료0을 확인했다.

[#114 후속 검증](a01-readiness-validation.md)은 실제 프레임으로 중복 원인을 분석하고 xiazh 0.15 후보를 개발7개에 비교한다. 중복 개선 없이 정상 연기 오탐이 추가돼 이 후보는 미채택이다. [모델 추천·평가 동결 제안·담당5 작업지](evaluation-freeze-and-handoff.md)로 xiazh 0.25 추천, 숫자 목표 제안, 평가 파일별 준비 조건과 실제 설명7개 원문/근거 인계를 구체화했다. 제안서는 아직 `PROPOSAL_NOT_FROZEN`이며 검수자를 대신 서명하지 않는다. 중복이 해결됐다거나 추가 모델 연구가 불필요하다고 주장하지 않는다.

같은 #114의 실제 서버 30분20초 반복 입력에서 3,641개 중 3,638개 분석·늦은 샘플 폐기3개를 확인했다. 전송3,639개·EOF·로그·3초 유효기간은 통과했고 관측 만료0이지만 **전체 샘플 처리 성공은 아니다.** xiazh 0.25의 장시간 누락 한계를 최종 모델 판단에 포함하며, 독립 정상 영상30분을 확보한 것으로 세지 않는다.

담당3의 CCTV 검출 화면·3D 카메라 위치 연결은 #74 / PR #115로 develop `3c58e47`에 반영됐다. 담당1의 API 인계를 기다리는 미구현 UI로 분류하지 않는다. 이번 검토는 최신 팀 변경을 포함하며 전체 WFI/배포 인수 검증과는 구분한다.

## 자동 보류한 잔여 항목

#118에서 [전체 영상 평가 집계](a04-suite-evaluation.md)를 추가하고 기존 개발7개 로그의 전체 지표를 재계산했다. 입력 누락·중복·모델/조건/환경 혼합과 독립 정답 미검수는 전체 집계에서 차단한다. #30/#41에 담당5 자료·검수 요청, #9/#12에 팀 결정 요청을 댓글로 남겼으며 자료가 오기 전에 평가 정답을 개발에 사용하지 않는다.

보류 항목은 상위 이슈를 닫거나 완료 체크하지 않는다. 평가용 정답을 개발·튜닝에 사용하지 않고, 이번 새 CAVIAR 3개를 포함한 개발 7개도 독립 평가로 옮기지 않는다. 새 목표/데이터/모델이 합의되면 기존 실패 기록을 보존하고 새 버전에서 비교한다.

## 재현·검토·정리

코드는 최신 develop의 문서와 실행 명령을 기준으로 한다. 모델·영상은 Git 밖이며 manifest/정답 해시로 일치 여부를 확인한다. `runs/`와 화면 원본은 실행 PC에 보존하고 공개 JSON의 입력/출력 해시로 연결했다. Fable 검토는 코드와 검사 증거에 대한 결함 검토이며 독립 영상/문장 성능 검수와 다르다.

검증에 만든 자체 서버·AI/설명 프로세스·SSH 터널·Vite·브라우저는 종료했다. 팀 공용 서비스·운영 방화벽·다른 역할의 제품 코드는 변경하지 않았다. 사용자의 승인 없이 진행해야 할 모호한 결정은 위 목록에 보류했으므로, 이번 인계를 전체 프로젝트 출시 승인으로 해석하지 않는다.
