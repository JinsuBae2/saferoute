# 1인칭 휴대폰 로컬 체험

사용자가 승인한 구성: 기존 유도등을 유지하고, 1인칭 오른쪽 아래에 손으로 든 휴대폰을 보여 준다. 휴대폰에 현재 서버 경로의 방향·층 이동 설명·미니맵을 표시한다. QR 확인과 휴대폰 열기/닫기는 대피 이동을 멈추지 않는다.

- 최신 develop 기반의 별도 로컬 브랜치에서만 작업한다. 푸시·PR·머지·배포하지 않는다.
- 방식: SVG 손과 CSS 휴대폰을 3D 화면 위에 겹친다. 실제 3D 손 모델은 제작 시간이 더 들고 글씨 가독성이 낮아 이번 체험에서 제외한다.
- 휴대폰은 처음부터 선택된 시연 인물의 경로를 보여 준다. 유도등 옆 QR에 가까워지면 위치 확인 연출을 추가로 할 수 있다. QR 인식은 장면 위치를 이용한 시연이며 실제 카메라 디코딩이 아니다.
- 방향·경로는 서버의 최신 경로만 사용한다. 경로 없음·통신 끊김·이전 실행에는 화살표와 경로선을 지운다. 미니맵은 실제 따라가는 사람의 층과 위치로 갱신한다.
- 현재 위치 선택 후 1인칭 진입은 같은 층의 가장 가까운 미탈출 인물을 고른다. 사람이 없으면 다른 층으로 넘어가지 않고 이유를 표시한다.
- 새 실행·다른 사람으로 전환하면 QR 확인 상태를 초기화한다. 소리를 켜지 않고 검증한다.
