# 점진적 시험 화재와 경로 변경

- 승인 범위: 사용자가 요청한 두 단계(작은 발화·불/연기 확산 표현, 확산에 따른 서버 경로 변경)를 로컬에서 구현·검증한다. 경보와 대피는 즉시 시작한다.
- 비교: 화면만 성장시키면 구역 일괄 차단이 남는다. 기존 감지기 경보를 늦추면 실제 경보 의미를 바꾼다. 따라서 위치를 지정한 **시험 화재만** 서버가 작은 공간 단위로 계산한다. 기존 AI·감지기 및 위치 없는 경보는 기존 정책을 유지한다.
- 방 내부는 2m 격자, 방 사이는 등록된 열린 문·복도·계단 연결을 사용한다. 닫힌 문·벽을 직선으로 건너지 않는다. 기존 공간·인원 정의는 바꾸지 않는다.
- 서버가 같은 시간의 불·연기 값과 차단 지점/통로를 계산해 하나의 상태로 보낸다. 휴대폰·유도등·사람은 기존 서버 경로를 계속 따른다.
- 계산은 시연용 모형이며 실제 연소·기류 예측이 아니다. 화염 4초/m, 연기 3초/m, 층간 추가 지연 화염 20초/연기 8초, 성장 화염 20초/연기 12초를 기본 가정으로 둔다. 차단은 화염 도달 또는 연기 값 0.5 이상이다.
- 화재 해제는 해당 시험 원인의 확산만 제거한다. 다른 화재·실제 경보·관측 만료는 유지한다. 초기화는 새 실행으로 모든 시험 확산을 비운다. 방마다 시간·상태를 분리한다.
- QR·인원 수·실제 경보·기존 지연 수정 보존. 최초 검증은 로컬에서 수행했다. 2026-11-12 후속 승인에 따라 #195로 최신 develop 통합·검증 후 PR/Squash merge하며 배포는 포함하지 않는다.
- WFI의 버전이 일치하는 형상 자료를 읽어 같은 구역 안의 벽도 격자 연결에서 제외한다. 등록된 문·계단 경로만 구역을 잇는다. 좁은 복도도 최소 한 줄의 격자를 유지하며 경로 가중치를 실제 거리로 사용하지 않는다.
- 해제는 시연 상태를 즉시 제거하는 동작이다. 실제 소화 후 남는 열·연기, 재료·환기·문 개폐에 따른 변화는 계산하지 않는다.
