자료 탐색과 선별 근거

이번 개선 목적
실내 건물 위험 감지에 필요한 정상 CCTV 초기 불꽃 연기 진행 혼동 사례를 보강
짧은 촛불과 이동 촬영 야외 연기만으로 성능이 충분하다고 판단하지 않음
모델 예측 점수로 선택하지 않고 촬영 환경 원본 기록 사용 조건과 표본 장면으로 선택

MmodalFire
공식 배포 https://springernature.figshare.com/articles/dataset/MmodalFire_A_Multimodal_Dataset_Comprising_Video_and_Physical_Sensing_Data_for_Detecting_Indoor_Fires/28804448
DOI https://doi.org/10.6084/m9.figshare.28804448.v1
공식 API https://api.figshare.com/v2/articles/28804448
CC BY 4.0은 저장한 배포 메타데이터의 라이선스 링크로 확인
원본 4929210010 바이트 RAR의 배포처 MD5를 대조하고 원본 영상 28개를 추출
선정된 실험실의 원본 시계와 실험표를 맞추어 15개의 연속 구간 82분을 발췌
면 액체 연료 폴리우레탄 목재의 발화와 연기 진행 7개
드라이아이스 2개와 가습기 미스트 2개
공식 blank control 2개와 정상 후보 준비 및 실험 사이 장면 2개
평가용 전체가 같은 실험실 촬영 그룹이라는 제한을 유지
실험실 장면 중에 카메라 방향을 조정하는 순간과 촬영자가 출입하는 부분도 있음
일부 불꽃은 작고 연기는 희미하며 짙은 연기에서 시야가 감소함
선택 영상의 일부 시점을 육안 확인했으며 전체 독립 사건 주석을 끝낸 것은 아님
실험표의 조도는 실험 기록이며 자동 노출로 화면 밝기가 단순 대응하지 않을 수 있음
요청한 시계 구간과 실제 원본의 초 단위 오버레이는 약 1초 차이가 있을 수 있음
주석에는 전달 파일 재생 시각을 사용

CAVIAR
공식 배포 https://homepages.inf.ed.ac.uk/rbf/CAVIARDATA1/
고정 카메라 실내 로비와 쇼핑센터 복도 정상 후보
로비 3개는 개발용 복도 6개는 평가용으로 촬영 장소를 분리
원본 384x288 25 FPS는 오래된 저해상도 조건이라는 제한을 명시
배포 페이지는 Creative Commons BY-SA를 표시하지만 버전 번호는 명시하지 않음
기존 MPEG의 일부 길이 메타데이터와 마지막 프레임 시각이 잘못되어 직접 입력 시 문제가 있었음
배포처가 명시한 25 FPS로 원본 디코딩 프레임 순서를 유지하고 시각을 다시 부여
프레임 수 보존과 길이 및 시각 역행 여부를 대조
H264 재인코딩 사실 원본과 전달본 해시를 함께 기록
원본 해상도를 키워 고화질 영상인 것처럼 표시하지 않음

FIRESENSE
공식 배포 https://zenodo.org/records/836749
DOI https://doi.org/10.5281/zenodo.836749
공식 API https://zenodo.org/api/records/836749
불꽃과 연기 아카이브 두 개의 배포처 MD5 대조
배포 메타데이터의 CC BY 4.0 확인
영상 표본을 확인하고 작은 불꽃의 고정 CCTV 두 장면 건물 외부 연기 한 장면과 색상 및 반사 혼동 두 장면 선정
실내 초기 감지 핵심 성능과 섞지 않고 별도 보조 자료로 구분
짧은 영상만으로 정상 시간당 오탐이나 장시간 지연을 충분히 평가할 수 없음
뉴스 로고나 분석 표시가 들어간 영상 벽난로 근접 화면과 관련성이 낮은 장면은 선택하지 않음
공개 벤치마크이므로 모델 사전학습에 포함되었는지 확인되지 않은 상태를 unknown으로 유지

다른 후보와 이전 묶음
MIVIA는 로그인 다운로드와 재배포 조건을 이 작업에서 확정하지 못해 전달 자료에서 제외
공개 이미지 데이터셋이나 합성 영상은 실제 연속 CCTV 평가 영상을 대신하는 자료로 채택하지 않음
이전 묶음의 이동 촬영 버스 짧은 거리 모닥불 야외 행사 영상은 이번 핵심 목록에서 제외
기존 개발 4개는 이미 개발에 사용한 이력을 보존하기 위해 동일한 바이트로 유지

현재 충분성 판단
Q01 출처 파일 해시 사용 조건 주석 계획 작성과 초기 정량 평가 준비에는 이전보다 목적에 맞는 자료
대규모 모델 재학습용 코퍼스나 여러 실제 건물의 안전성 검증 자료는 아님
실내 핵심 촬영 장소는 두 곳이며 화재가 있는 장소는 한 실험실에 집중됨
정상 후보가 모두 정상으로 확정되어도 시간당 드문 오탐을 신뢰성 있게 입증할 만큼 길지는 않음
실제 적용 건물의 허가된 정상 CCTV를 낮과 밤 및 여러 카메라에서 추가 확보하는 것이 다음 보강 과제
직접 화재를 일으켜 영상을 만들 필요는 없으며 기존 검증 자료와 적법하게 확보한 현장 정상 영상을 활용
최종 모델과 설정 고정 후 전체 결과 누락 오탐 지연 실패 실행을 함께 보고해야 함
